# NexusCanvas

Infinite spatial note board with wiki-links, frames, diagram shapes, and media.

## Highlights (v0.6)

- **Frames** — collapse (▾) or auto title-only when zoomed out
- **Minimap** — bottom-right pill, expand for overview / click-to-pan
- **Image autofit** — photo nodes match image aspect ratio
- **Zoom-safe chrome** — controls scale with the board (em + `--nx-z`)

## Run

```bash
npm install
npm run dev
```
